# 东方红魔乡：新典数据相关工具

**[English](README.EN.md) | [日本語](README.JA.md) | 中文**

本仓库基于逆向工程实现了`东方红魔乡：新典`打包格式的解包和封包工具

## 使用方法   

### 通过cargo安装
```bash
cargo install --git https://github.com/XuanRikka/th06nc-data.git
```

### 下载Release的预构建版本
在Release里选择对应的平台下载

### 从源码编译
你都选择这么干了真的需要我告诉你怎么做吗

## 额外说明
 - 打包加密和文件名强相关，除非你知道你在干什么，否则不要修改文件名
 - 打包格式内没有路径的概念，所以如果你的打包路径里有两个名字相同的文件那将是未定义行为
 - 被打包的文件名必须是纯ASCII
 - 每个封包文件末尾都固定有一个`ver0102.dat`文件，如果你在重封包的时候目录里有这个文件，那么请添加`--no-ver0102`防止重复存储
 - 封包文件里必须在末尾有一个`ver0102.dat`
