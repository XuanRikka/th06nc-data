# 東方紅魔郷: New Classic データ関連ツール

**[中文](README.md) | [English](README.EN.md) | 日本語**

本リポジトリは、リバースエンジニアリングに基づいて`東方紅魔郷: New Classic`のパッケージ形式を展開（アンパック）／再パックするツールを実装したものである。

## 使い方

### cargo でインストール
```bash
cargo install --git https://github.com/XuanRikka/th06nc-data.git
```

### Release のビルド済みバイナリをダウンロード
Release からお使いのプラットフォーム向けのものを選んでダウンロードする。

### ソースからビルド
そこまで自分で選んだのなら、やり方を教える必要はないですよね？

## 補足
 - パック時の暗号化はファイル名と強く結びついている。何をしているか理解していない限り、ファイル名を変更しないこと。
 - パッケージ形式にはパスの概念が無いため、パック対象のディレクトリ内に同名ファイルが 2 つある場合、一方はスキップされます。
 - パックするファイル名は純粋な ASCII でなければならない。
